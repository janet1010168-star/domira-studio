# 乐龄全屋规划

复用最新版 home-studio.js 的图纸压缩、视觉识别、尺寸及房间核对流程；构建后使用 home-domain.js / home-scene.js 建立全屋建筑模型。新增 care-whole-home.js 保存逐房 Care 专案，以全屋坐标展示、房间局部坐标编辑，避免房间切换串改家具。全屋产品按用途分配至首个合适房间，没有合适位置保留未放入记录，不缩小产品。短边不足2m的房间仅保留建筑模型，需人工设计。全屋通行、门位与安装仍需现场核对，不产生全屋合规证书。

41㎡示例来自2021年人口普查长者专题：含65岁以上长者住户的居所面积中位数41.0㎡，不是平均值，也不是独居长者专属统计。外框6.4×6.40625m，五个矩形净面积合计41㎡；墙厚不额外计入。房间比例、门位、2.7m层高全部为展示假设，不代表真实物件。来源：https://www.censtatd.gov.hk/en/data/stat_report/product/B1120118/att/B11201182021XXXXB0100.pdf

渲染复用原有 createRenderStudio：进入房间选择五个视角，可生成保真3D参考图及现有AI氛围图。保真图保留模型，AI图不能作为精确尺寸证据；API、访问码、持久化和幂等沿用原服务。对话助手 POST /api/care/chat，默认沿用渲染提示文字模型 DEEPSEEK_API_KEY / deepseek-flash，密钥只在服务端。可用 CARE_CHAT_* 覆盖配置。对话仅给建议，不自动改动模型；未配置明确503，不伪造回复。图像生成模型不能直接充当文字聊天模型。

验收：41㎡尺寸合计；逐房保存/切换与全屋坐标；平面图导入后核对；产品按用途分配；全屋JSON/SVG导出；五视角渲染入口；对话失败与真实API状态；390px响应式。实际测量、全屋轮椅路线及真实设备AR另行验收。
