# Layout Agent 動線優化

`v2.0` 的「適老與動線」面板新增 **Layout Agent 優化擺位**，處理目前房間中已選定的家具。同步包含 GitHub 合併的淨空驗算、牆邊吸附、活動能力分檔及新增家具；補上吸附函式的前端匯入，修復拖動時的執行錯誤。

## 模組與資料流

- `worker/layout-optimizer.js`：擴充既有 `LayoutAgent`，將目前房間、有效門窗、活動需求及家具尺寸與擺位交給 DeepSeek。每次操作只呼叫一次，關閉 thinking、輸出上限 3500 tokens、25 秒逾時，不自動重試。不使用報價 agent 的離線示例冒充優化。
- `POST /api/layout/optimize`：接收 `room/items/style/purpose/config`。每間限 1–24 件家具、160 m²；`config` 含 `profile/entry/offset/targetId` 及可選的已知 `door`。AI 最多提出三個完整候選，只可輸出已有 ID 的 `x/z/rotation/reason`。
- `public/layout-optimization.js`：服務端與瀏覽器共用的驗算。固定水槽、煮食爐與 locked 家具不可搬動；保留所有家具及尺寸、型號、品牌、材質和港幣價格。驗證旋轉占地、房間邊界、門前通行區及家具正面方向；拒絕新增、刪除、改尺寸、碰撞或越界。優先新增可達家具，其次縮短所選路程或減少轉向，且原本可達的家具不能變成不可達。
- `public/circulation-domain.js`：入口邊界到室內起點、精確起終點到網格的連接段均檢查家具淨空。簡化網格折線時檢查整段與旋轉矩形的距離，避免切角穿越家具；以實際距離插值小人步行，線段中途的地毯也列入提醒。
- `public/circulation-studio.js`：展示目前／建議的可達數量、路程、轉向與移動清單。家具在使用者按「套用擺位並播放動線」後才改變，接續現有搜尋、路線與小人解說動畫。房間、家具、風格、用途或需求改變後舊提案失效。
- `public/app.js`：只合併候選的座標及朝向，建立復原節點、更新預覽與本機專案；沿用既有渲染快照失效機制，避免把舊效果圖當成新布局。新生成布局也傳入活動能力對應的通道目標。

## 驗收

1. 同一份兩件家具測試場景可將繞行改為直接路徑；比較值由幾何計算產生。
2. 固定設備、價格和產品資訊不受套用影響；可復原。
3. 假 ID、重複、漏件、改尺寸、非有限座標、越界、重疊、門區阻塞或可達性退步的候選不會套用。
4. 入口薄障礙、目的正面阻塞、家具隔斷及不足的已知門寬不會回報可通行。
5. 模型錯誤、未連線、逾時或無改善時保留原設計；無自動付費重試。
6. 執行完整 Node 測試、Worker 建置及雙 bundle 檢查；發布後核對 GitHub、前端與 API 同一 SHA 及所有靜態檔案雜湊。

這是單間平面家具占地的設計檢查。未知門窗不會虛構；跨房夜間動線仍使用既有粗估，不會包裝成實際步行路線。門扇、高差、地面狀況、座高與輪椅轉向空間仍需現場核對。
